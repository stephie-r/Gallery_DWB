# Título de la galería : Taller Las Vueltas de Luz

- El tema elegido es la creación de productos de forma artesanal disfrutando del momento de creación y las clases dadas en el taller.
- Las Vueltas de la Luz es un taller de alfarería donde se enseñan los procesos de creación de piezas cerámicas, materialidades, tipos de arcilla y terminaciones.
- El objetivo de la galería es dar una idea al usuario de los distintos elementos que se encuentran en el taller, al igual que los procesos que se enseñan. Mostrando los proyectos en proceso de los alumnos. Esto se ejemplifica para que pueda tomar una decisión informada de si quiere participar del taller y entender la modalidad de las clases.
